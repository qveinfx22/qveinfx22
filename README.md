# Привет! Я Python-разработчик 👋

Специализируюсь на Backend-разработке веб-приложений, создании мощных Telegram-ботов и веб-скрейпинге (парсинге). Помогаю бизнесу автоматизировать процессы, разрабатываю надежную логику для сайтов и связываю различные сервисы между собой.

---

### 🛠 Технологический стек:
* **Язык программирования:** Python 🐍
* **Backend & Web-разработка:** FastAPI, Flask, основы Django, базовый HTML/CSS
* **Базы данных:** PostgreSQL, SQLite, SQLAlchemy, ORM
* **Парсинг и сбор данных:** BeautifulSoup, Requests, Selenium, Lxml
* **Telegram-роботы:** Aiogram, Telebot, Telegram Web Apps (TWA)
* **Работа с данными:** Pandas, Openpyxl (Excel), JSON / REST API

---

### 📂 Моё портфолио (Примеры готовых решений):

#### 🌐 Web-разработка & Backend (Создание сайтов и API):
* **[Business Dashboard API](#)** — Разработка серверной части (Backend) для корпоративного веб-сайта на базе FastAPI. Реализация системы авторизации, CRUD-операций, подключение базы данных PostgreSQL и создание удобной админ-панели для управления товарами и заказами.
* **[Telegram Mini App (Web App)](#)** — Разработка полноценного веб-сайта-магазина, который открывается прямо внутри Telegram. Интеграция фронтенда с Python-бэкендом для бесшовного оформления заказов.

#### 🤖 Telegram-боты для бизнеса:
* **[LeadGen Business Bot](#)** — Интерактивный бот для сбора заявок и технической поддержки. Автоматически квалифицирует клиента, собирает контакты и мгновенно пересылает структурированную заявку администратору (или сохраняет в БД).

#### 📊 Парсинг, скрейпинг и аналитика данных:
* **[DataExtractor Web Scraper](#)** — Универсальный парсер интернет-магазинов и маркетплейсов. Обходит защиту, собирает цены, артикулы, характеристики товаров и формирует готовые прайс-листы в `.xlsx` или автоматически загружает их на сайт через API.
